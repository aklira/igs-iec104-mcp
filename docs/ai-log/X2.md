# X2 — Published server endpoints

## Prompt

Task X2 of `IMPLEMENTATION.md` §14: published server endpoints. Depends on D2. Done when a client outside Docker reaches
a managed server at the advertised endpoint on Linux and on Docker Desktop/WSL.

## Summary

- `models/instance.py`: a station may declare `publish` (its port in the bench, the host port, the host address, and the
  advertised endpoint); a client may not.
- `docker/plan.py`: a published station imposes its listening port; two stations cannot publish one host port.
- `docker/specs.py`, `docker/adapter.py`: a container publishes one named port at a named address, as the spec says.
- `docker/bench.py`: a published station gets its relay on the control network; its endpoint is `RunningBench.advertised`.
- D-035 records the decisions, and what the done-when still needs.

Dependencies: none new.

## Verification

- `tests/unit/test_publication.py` (12 tests) passes with warnings as errors; the unit suite passes (342 tests); the
  schema check matches the models after the instance change.
- `tests/integration/test_docker_publish.py` passes on Podman with the images built from this repository: a runtime on the
  host connects to the advertised endpoint, starts its transfer, interrogates, and reads 12.5; the bench is then removed,
  and its stop is graceful.
- The whole integration suite passes on Podman (24 tests, about 6 minutes).
- Gates: `ruff format --check`, `ruff check`, `mypy` (strict, 75 source files).

## Decisions

- D-035: the publication in the definition; the imposed port; the relay on the control network; the advertised endpoint;
  what is not in X2.

## Open

- The done-when names Docker Desktop and WSL. Only Linux with Podman has run here. X2 is not ticked until that is
  decided: the Docker Desktop check, or a recorded decision that the Linux result is enough for now.

## Points for the next tasks

- X3 (an independent implementation as the other end) is a human gate; M3 (confirmation on external targets) is next in
  the plan.
- A published port carries the IEC protocol to the host without authentication beyond the protocol's own; the default
  bind keeps it on the loopback. A wider bind is an explicit choice of the definition.

## Size

About 120 lines of the definition, plan, spec, adapter, and bench changes, and about 230 lines of tests. Above the
roughly 400 lines of §2 counting the tests, because the publication touches four layers that work only together.
