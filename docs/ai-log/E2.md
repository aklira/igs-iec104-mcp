# E2 — Assertions

## Prompt

Task E2 of `IMPLEMENTATION.md` §14: value, quality, type, common address, IOA, cause, and timestamp assertions
with tolerances. Done when unit tests cover each matcher, its tolerance, and its failure message.

## Summary

- `models/scenario.py`: the two assertion steps gain the conditions that are optional and checked only when named:
  `common_address`, `cause` (1 to 63), `stamped` (the time tag), and `quality` (optional flags). The published
  scenario schema is regenerated.
- `scenarios/assertions.py`: the matchers (`value_matches`, `mismatches`), the observation of a point event, the
  kind of each monitoring type, and the handlers `assert_point` (the point image) and `expect_point` (an observation
  after the cursor). `ASSERTION_HANDLERS` maps the two actions.
- `scenarios/engine.py`: the `Source` gains the point image; `Observation` is the value a client received; a handler
  can leave a note that the engine adds to a TIMED_OUT verdict.
- D-026 records the decision and the split: the runtime-backed source is E2b.

Dependencies: none new.

## Verification

- `tests/unit/test_scenario_assertions.py`: a number within its tolerance matches and one outside does not; without a
  tolerance a number must be exact; a boolean is never a number (`True` is not `1`); an object must be equal; the
  value mismatch message names the received value, the expected one, and the tolerance; the kind is checked against
  the type, and an unknown type is named by its number; the common address, the cause, and the time tag are checked
  only when named, each with its message; a named quality flag is checked and an unnamed one is not; an absent flag
  counts as not set; every condition gives its own message; `assert_point` passes on the image, fails when the point
  has no value, and reports every mismatch at once; `expect_point` takes an observation after its cursor, never one
  from before it, and times out with the last mismatch; a scenario of both kinds passes, and stops at the first
  failure with fail-fast.
- `tests/unit/test_scenario_engine.py`: updated for the source's image; the ten engine tests still pass.
- Gates: `ruff format`, `ruff check`, `mypy` (strict, 54 source files), the unit tests (241 pass), and the schema
  check (`--check`).
- Found while testing: a boolean compared with `1` matched (Python treats `True == 1`); fixed, with the test that
  caught it.

## Decisions

- D-026: the matchers, the conditions of the steps, the note on a timeout, and the split of the runtime-backed source
  into E2b.
