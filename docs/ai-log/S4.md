# S4 — Runtime point kinds (part S4a: counter)

## Prompt

Task S4 of `IMPLEMENTATION.md` §14, added after D2 (D-019): the runtime serves the five point kinds it does
not serve yet (counter, step, bitstring, packed, normalized-unqualified), on the station and in the client's
point image. This commit is the first part, S4a: `counter`. The rest is split (D-021).

## Summary

- `runtime/igs-iec104-runtime/src/points.rs`: the `counter` kind, with its form (a 32-bit integer), its JSON
  value, and the refusal of a ramp or a walk on a counter (those need a measured point).
- `src/image.rs`: the decoding of M_IT_NA_1 and M_IT_TB_1 into the point image, with the invalid flag as the
  quality.
- `src/lib.rs` and `contracts/`: the contract is 1.3.0, with `counter` in the point kinds of the API and the
  additive change recorded in both event schemas.
- `docker/plan.py`: `counter` is served, so a bench that uses it is accepted.
- D-021 records the decision and the split of S4.

Dependencies: none new.

- Python: `tests/unit` (216 pass), and `tests/integration` against the local runtime binary: the contract test

- The counter round trip is tested on the wire: a station serves a counter, an update is sent, and the upstream
  client receives it as a spontaneous M_IT with the new value.
