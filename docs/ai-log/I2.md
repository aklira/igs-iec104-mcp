# I2 — Read-only preflight

## Prompt

Task I2 of `IMPLEMENTATION.md` §14 (Phase I, issue #1): a read-only preflight of the prerequisites, run as
`python -m igs_iec104_mcp.doctor`, with a human-readable table, a `--json` output, and a nonzero exit on a failure. No
check runs a privileged or state-changing command.

## Summary

- `src/igs_iec104_mcp/doctor.py`: the checks (host, Python, uv, Rust against the pin, OpenSSL development files, the
  engine, the `claude` and `codex` CLIs, and the project directory when given), the report, the text and JSON output, and
  `main`. The Podman socket is tried first, then the Docker socket; `DOCKER_HOST` overrides both.
- `tests/unit/test_doctor.py`: 24 tests with a probe that answers from a table. They cover each check's OK, WARNING, and
  FAIL, the engine choice and its refusals, the permission message, the project directory (which is never created), the
  text and JSON output, and the exit code.
- `DECISIONS.md`: D-057, the read-only rule, the statuses, and the engine order.
- `IMPLEMENTATION.md`: I2 ticked in §16.

## Environment

`uv` was not installed on this machine, so the locked environment could not be built. I installed `uv` 0.13.1 with the
official installer into `~/.local/bin`, outside the project, and ran `uv sync --locked`. This is the prerequisite of
`docs/setup.md`.
